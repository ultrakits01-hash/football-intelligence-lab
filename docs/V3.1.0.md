# FIL v3.1.0 — Youth Scout Desk

- Wonderkids now persist the exact `fil_dataset_id` + `fil_player_id` discovered during enrichment. Open Player Lab uses that exact route; no second identity search is needed.
- Older cached prospect rows still fall back to the global resolver.
- New Prospect Compare desk: compare up to four youngsters on sourced market value, senior minutes, evidence coverage and FIL analytics availability.
- New Wonderkids lenses: FIL analytics linked and Saved prospects.
- Compare actions are available directly on cards and inside prospect dossiers.
- Evidence/value comparisons remain descriptive; FIL does not generate potential ratings.

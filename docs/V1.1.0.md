# FIL v1.1.0 — Player Lab analytics correction

- Product dataset catalogue now starts at 2025/26; legacy development seasons remain on disk but are hidden.
- Understat Player Lab uses real shot-location density when generic event XY is unavailable.
- Understat Player DNA only displays dimensions supported by its actual player-season metrics.

- Player Lab shot outcomes use a high-contrast outcome palette independent of Match Lab team colours.
- Goal history renders the actual home/away fixture and score; Understat ingestion stores opponent context.

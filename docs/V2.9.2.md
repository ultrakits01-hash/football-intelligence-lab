# FIL v2.9.2 — Wonderkid Player Resolution Hotfix

- Wonderkid cards no longer trust cross-dataset/local numeric IDs as portable Player Lab identifiers.
- Clicking a FIL-linked prospect switches to the recorded dataset, then resolves the player by name + club inside that dataset before opening Player Lab.
- Falls back to exact name and hinted local ID only after the target dataset is active.
- Global-only catalogue prospects remain scouting records and do not fabricate Player Lab profiles.
- Clear coverage state is shown when a catalogue prospect cannot be resolved to installed FIL analytics.

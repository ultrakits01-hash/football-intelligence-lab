# FIL v1.6.1 FINAL RC2

Release QA hotfix after real-dataset testing.

- Global Similar Players now uses tiered tactical-role -> position-group fallback, so sparse provider position labels no longer leave the panel empty.
- Global candidate identity de-duplication collapses repeated provider records and conservative short-name aliases within the same club.
- Team Lab now presents league positions as ordinal ranks (1st, 2nd ... Nth) while retaining percentile bars internally for visual scale. Defensive lower-is-better metrics rank correctly.
- ScoutLab adds Wide creator, Deep playmaker, Box-to-box, Poacher, Inside forward and Screening midfielder role presets.
- Missing data is still never converted to zero for similarity.

# FIL v8.0.0 — World Cup Interactive Intelligence

- Rebuilt World Cup visual system with navy/slate cards instead of near-black panels.
- Nation cards now open Nation Squad Hubs with tournament record, squad, goals/assists when source-supported, and matches.
- Match cards are clickable and keep the list clean: metadata + score only. Goal events move into a Match Hub.
- Correct result display: extra-time score supersedes 90-minute FT where supplied; penalty shootouts are labelled separately.
- Group cards open Group Intelligence with standings, group scorers, nation links and group-only matches.
- Leaders now support clickable Player Lab links and an assists panel only when the installed source actually provides assist attribution.
- No fabricated assists or advanced tournament metrics.
- Existing Player Lab timeout/race-safety architecture preserved.

# FIL v1.5.0 RC3 — Global Similarity + Live Transfer QA

- Similar Players now searches the installed current-generation FIL universe, not only the active league.
- Exact-position/role constraints remain; missing metrics are excluded rather than zero-filled.
- Same player duplicated across competitions is deduplicated conservatively.
- Similar-player cards carry their source dataset route so cross-league clicks open the correct Player Lab record.
- Live Transfer Centre has a built-in public RSS fallback for reported transfer headlines, plus the existing structured JSON adapter for verified/confirmed feeds.
- RSS items are always labelled Reported; FIL never upgrades a headline to Confirmed.
- Transfer feed remains isolated from analytics if the network/provider is unavailable.
- UI empty/error states and card interaction received a final visual pass.

# Football Intelligence Lab v1.2.0 — Release hardening

Release-focused audit of the current 2025/26+ intelligence platform.

## Hardening
- Unified frontend/API/release-readiness version reporting at 1.2.0.
- World Cup JSON payloads are cached by file mtime/size and automatically invalidated after imports.
- Player Lab keeps the core profile as the only required request; optional similarity/map/spatial enrichment has tighter independent budgets.
- Missing numeric provider values render as `—` instead of silently becoming zero.
- Player facepack manifest is non-blocking, cache-busted and images decode/lazy-load independently.
- Added a harmless favicon response to remove noisy 404s from development logs.
- Removed generated Python bytecode from the release archive.

## Release checks
`/release-readiness` reports the actual release version and checks installed current datasets plus World Cup source health. No third-party scraping runs in the browser or API.

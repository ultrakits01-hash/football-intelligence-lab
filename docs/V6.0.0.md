# FIL v6.0.0 — Intelligence Platform

Major platform update built on v5.1 adaptive player intelligence.

## New: FIL Rankings
Transparent, position-specific league benchmarking for GK/DEF/MID/FWD. The profile percentile is an equal-weight mean of available role-relevant peer percentiles; missing metrics are ignored and coverage is displayed. It is not an overall rating.

## New: Development Lab
Search one player across every installed FIL dataset. Season, competition and provider contexts stay separate so unlike sources are never silently blended. Tracks minutes/goals/assists plus available attacking, creation, progression, defensive and goalkeeper per-90 metrics.

## Wonderkids
Prospect dossiers now link directly into Development Lab as well as Player Lab and Prospect Compare, connecting youth discovery to the player's installed multi-season evidence.

## Player Lab
v5.1 adaptive role intelligence and cross-provider spatial recovery are preserved as core behaviour: genuine XY when installed, useful role-specific statistical intelligence otherwise.

## Stability and data integrity
Sparse/null provider fields remain unavailable rather than zero. Existing lazy loading, request caching, dataset-scoped navigation, Recruitment Intelligence realism gates, rival blocking, Data Hub and Career Intelligence remain intact.

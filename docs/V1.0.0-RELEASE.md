# Football Intelligence Lab v1.0.0 RELEASE

Release hardening pass.

- Carries forward v9-v12 World Cup navigation, XI/bench/substitution/card/event and loading fixes.
- Player Lab media layer now uses a manifest and supports large editorial player cut-outs with initials fallback.
- Bundles the user-supplied Florian Wirtz cut-out.
- Adds `scripts/ingest_player_images.py` for building a local facepack from Wikimedia Commons while accepting only permissive licenses and retaining source/author/license metadata.
- Player profile remains the required request; similarity/spatial enrichment remains optional and bounded.
- No image hotlink dependency: downloaded facepack assets are local.
- No fabricated World Cup assists, xG, formations, or event coordinates.

# FIL v7.0.0 — World Football Intelligence

## World Cup 2026
- New top-level World Cup Intelligence workspace.
- 48-nation squad explorer, groups/tables, 104-match browser, tournament goal leaders and result cards.
- New `scripts/ingest_world_cup_2026.py` downloads the public-domain openfootball 2026 match, squad and full-match JSON files.
- World Cup squad players can link into installed FIL club-season analytics by identity. Club statistics are never relabelled as tournament statistics.
- Tournament data remains a separate provenance layer so future xG/event providers can be added without contaminating source meaning.

## Player Lab reliability
- Player requests now have hard time limits.
- Optional Similar Players, map and cross-provider spatial calls cannot spin forever.
- Failed/timed-out player loads terminate in a retryable error state rather than an infinite `LOADING PLAYER INTELLIGENCE…` screen.
- Existing abort/race protections are preserved.

## Platform preservation
- Adaptive Player Intelligence, cross-provider spatial recovery, Data Hub, Development Lab, Rankings, Recruitment Intelligence and Prospect Intelligence remain intact.

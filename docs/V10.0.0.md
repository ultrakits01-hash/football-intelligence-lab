# FIL v10.0.0 — Release Candidate

This build folds v9.0.1 reliability into the main release line and focuses on ship-readiness.

## Release gates
- World Cup navigation uses delegated routing.
- Match identity reconciliation from v9.0.1 is retained.
- Release-readiness endpoint reports API, current-era datasets and World Cup source health.
- Match failures expose recovery actions rather than permanent loading/dead states.
- Cache-busted frontend assets prevent stale pre-RC JavaScript.

No provider data is fabricated and no missing value is coerced into evidence.

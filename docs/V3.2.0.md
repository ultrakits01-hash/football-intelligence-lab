# FIL v3.2.0 — Prospect Analytics

- Atomic Wonderkids → Player Lab hand-off via `/resolve-player-profile`; the resolved profile itself is passed into Player Lab, eliminating the second lookup that caused valid linked prospects to fail.
- Prospect Compare now compares actual football output where FIL has it: attacking, creation, passing, carrying, defensive and goalkeeper metrics are surfaced dynamically.
- Missing metrics render as unavailable rather than zero.
- Existing value/minutes/evidence context remains separate from football performance and is not presented as potential.

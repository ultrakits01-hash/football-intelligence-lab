# FIL v1.0.1 — Facepack v2

- Fixed `--from-installed`: scans SQLite, CSV and JSON datasets instead of SQLite only.
- Wikimedia Commons discovery now separates search from metadata retrieval, ranks candidates and verifies machine-readable licence metadata.
- Adds retries, identified User-Agent, progress diagnostics and incremental manifest saves.
- Adds `--folder` for user-supplied transparent PNG/JPG/WebP renders. FIL does not scrape third-party render sites.
- Existing manifest images no longer consume the requested `--limit`.
- Player Lab image manifest cache bumped to v1.0.1.

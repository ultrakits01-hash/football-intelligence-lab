# FIL v2.0.0 — Big-5 Foundation

- Adds one-command complete Big-5 2025/26 ingestion (`scripts/ingest_big5.py 2025`).
- Each league import includes league players, all fixtures/results, team xG/PPDA/deep/xPTS history, completed-match rosters/player output and shot XY/xG.
- Position-aware Player Lab: forwards, midfielders and defenders use different provider-supported profiles.
- Understat goalkeepers no longer receive attacker DNA, shot-density or empty shot-map panels.
- Understat defenders carry an explicit scope note: buildup/involvement is not defensive ability.
- Provider capability gating remains strict: no fabricated saves, tackles, interceptions, passing networks, heatmaps or tracking data.

# FIL v2.6.0 — sourced market values

- Adds a dedicated market-value reference layer using the public `dcaribou/transfermarkt-datasets` snapshot.
- Market values are provider-derived facts, never FIL estimates or transfer-fee predictions.
- Values are matched conservatively to installed 2025/26 and 2026/27 player identities and retain source/date metadata.
- Player Lab, global player search, ScoutLab and cross-league Transfer Lab can all receive the same value metadata.
- Transfer Lab now shows sourced values beside current-squad and candidate players when available.
- Missing/unmatched values remain absent rather than being converted to zero or guessed.

Run `python scripts/ingest_market_values.py` after your league imports to build/update the local reference index. The upstream public snapshot is currently historical (latest valuations June 2026), so FIL labels it as dated source data rather than pretending it is live.

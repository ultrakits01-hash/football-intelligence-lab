# FIL v5.1.0 — Adaptive Player Intelligence

- Replaces dead Player Lab map placeholders with role-specific aggregate intelligence when XY evidence is unavailable.
- Midfielders receive progression/use, creation, defensive work and goal-threat clusters from real installed metrics.
- Defenders receive defending, build-up and attacking-support clusters.
- Goalkeepers and forwards receive position-specific alternatives when their provider supports them.
- Adds cross-provider spatial evidence discovery: if the active dataset has no coordinates, FIL can use a genuine installed map for the same player from another provider, prioritising the same competition and season.
- Spatial provenance is shown in the panel. FIL never synthesises coordinates from aggregate statistics.
- Missing metrics remain unavailable rather than zero.

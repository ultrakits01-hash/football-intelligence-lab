# FIL v9.0.0 — World Cup Intelligence III

## Big patch
- Reworked World Cup → Player Lab hand-off. If no installed club dataset resolves, FIL now opens a World Cup-native player profile instead of a browser alert.
- Added player profile cache and shorter bounded profile resolution to reduce recurring Player Lab loading stalls. Optional spatial evidence can no longer kill an otherwise valid profile.
- Added FIL-owned national identity marks. These are generated UI marks, not official federation crests.
- Expanded Nation Hub with starts/appearances/cards when present in `worldcup-full.json`, squad contribution rows, top scorers and tournament record.
- Expanded Group Hub with goals, match count and player leaders derived only from installed tournament evidence.
- Expanded Match Hub with clean line-up rendering, timeline, bookings/substitution counts and player links.
- Added World Cup-native player profiles with tournament goals, source-attributed assists, starts, appearances and discipline where supported.
- Preserved FT/ET/penalty result handling from v8.

## Data policy
Openfootball remains the automated World Cup source. FotMob was reviewed as a useful visual/reference benchmark, but v9 does not scrape or bulk-ingest FotMob. Advanced stats are only shown when a permitted installed provider supplies them. Missing evidence remains missing.
